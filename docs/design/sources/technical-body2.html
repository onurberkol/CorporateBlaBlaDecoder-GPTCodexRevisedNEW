compose handler — auth, doğrulama, kota, gating, maskeleme

Akış her zaman aynı sırada: kimlik → girdi doğrulama → kota (sunucu) → persona sanitizasyonu (premium-gate) → prompt → Claude → doğrula → free kullanıcıda premium tonları maskele. Premium ton metni sunucuda boşaltılır; kilitli içerik istemciye hiç ulaşmaz ama kullanıcı tonların var olduğunu görür (dönüşüm için).

functions/src/compose.ts (özet)
export const compose = onCall(
  { region: REGION, secrets: [ANTHROPIC_API_KEY], memory: '256MiB',
    timeoutSeconds: 30, enforceAppCheck: ENFORCE_APP_CHECK },
  async (req) => {
    const uid = req.auth?.uid;
    if (!uid) throw new HttpsError('unauthenticated', 'Sign-in required.');

    const { intent, locale, persona } = (req.data ?? {}) as ComposeRequest;
    if (typeof intent !== 'string' || !intent.trim())
      throw new HttpsError('invalid-argument', 'intent is required.');
    if (intent.length > MAX_INPUT) throw new HttpsError('invalid-argument', '...');

    const { tier, remaining } = await consumeQuota(uid, 'compose'); // kotanın TEK yeri
    const safePersona = sanitizePersona(persona, tier === 'premium');// ton hafızası premium-only

    const system = buildComposerSystemPrompt(locale, safePersona);
    const result = await completeJSON<ComposerResult>(client, { system, user: intent.trim(), maxTokens: 800 });
    validateComposer(result);

    const locked = tier === 'free' ? PREMIUM_TONES : [];
    for (const tone of locked) result.variants[tone] = '';          // kilitli ton metnini sunucuda boşalt
    return { result, meta: { tier, remaining, locked } };
  }
);

sanitizePersona ayrıca suistimali sınırlar: yalnızca premium kullanıcıda çalışır, en fazla 5 örnek × 500 karakter alır, isim 60 karaktere kapanır. decode handler'ı aynı iskelete sahiptir; tek farkı withDefense'in yalnızca premium'da onurlandırılması (allowDefense = tier === 'premium' && withDefense === true) ve free kullanıcıda defense alanının silinmesidir.

Kota — yarış-koşulsuz transaction (quota.ts)

Kota bir Firestore transaction'ında atomik olarak okunur ve artırılır; iki eşzamanlı istek limiti aşamaz. Gün, RESET_TZ (varsayılan UTC) zaman diliminde YYYY-MM-DD anahtarıyla hesaplanır; tarih değişince sayaç sıfırlanır. tier burada okunur ama yazılmaz (onu webhook yazar).

functions/src/quota.ts (çekirdek)
return db.runTransaction(async (tx) => {
  const data = (await tx.get(ref)).data() ?? {};
  const tier = data.tier === 'premium' ? 'premium' : 'free';   // eksik doc → free
  const usage = data.usage?.date === day ? { ...data.usage }
                                         : { date: day, decode: 0, compose: 0 };
  if (tier === 'free' && (usage[action] ?? 0) >= FREE_LIMITS[action])
    throw new HttpsError('resource-exhausted', `Daily free limit reached for ${action}.`);
  usage[action] = (usage[action] ?? 0) + 1;
  tx.set(ref, { tier, usage, lastSeen: FieldValue.serverTimestamp() }, { merge: true });
  return { tier, remaining: /* free: kalan, premium: null */ };
});

Claude çağrısı — güvenilir JSON (anthropic.ts)

Model'den yapılandırılmış çıktı almanın iki numarası: (1) asistan turunu { ile prefill etmek — model bir JSON nesnesi ve başka hiçbir şey üretmeye zorlanır; (2) ilk parse başarısız olursa düşük sıcaklıkta bir kez retry. parseLoose kod-çitlerini soyar ve en dıştaki süslü parantezlere keser.

functions/src/anthropic.ts — completeJSON
export async function completeJSON<T>(client, { system, user, maxTokens, temperature = 0.8 }): Promise<T> {
  const primary = await client.messages.create({
    model: MODEL, max_tokens: maxTokens, temperature, system,
    messages: [ { role: 'user', content: user },
                { role: 'assistant', content: '{' } ],   // ← prefill
  });
  try { return parseLoose<T>('{' + textOf(primary)); }
  catch {
    const retry = await client.messages.create({ /* temperature: 0.2, "Return ONLY the JSON object." */ });
    return parseLoose<T>('{' + textOf(retry));
  }
}

RevenueCat webhook — users.tier'ın tek yazarı (revenuecat.ts)

Bu onRequest fonksiyonu, sistemde tier'a yazan tek yerdir. RevenueCat'i buraya Authorization başlığı REVENUECAT_WEBHOOK_AUTH secret'ına eşit olacak şekilde POST atmaya yapılandırırsın; app'in RevenueCat appUserID'sini Firebase uid'ine eşitlersin, böylece app_user_id doğrudan kullanıcı belgesine map'lenir.

functions/src/revenuecat.ts (çekirdek)
const ACTIVE = new Set(['INITIAL_PURCHASE','RENEWAL','UNCANCELLATION',
  'PRODUCT_CHANGE','NON_RENEWING_PURCHASE','SUBSCRIPTION_EXTENDED']);
const INACTIVE = new Set(['EXPIRATION','SUBSCRIPTION_PAUSED']);  // iptalde değil, SÜRESİ DOLUNCA düşür

export const revenuecatWebhook = onRequest({ region: REGION, secrets: [REVENUECAT_WEBHOOK_AUTH] },
  async (req, res) => {
    if (req.headers.authorization !== REVENUECAT_WEBHOOK_AUTH.value())
      return void res.status(401).send('unauthorized');
    const e = req.body?.event;
    if (ACTIVE.has(e?.type))   await setTier(e.app_user_id, 'premium', e.expiration_at_ms);
    else if (INACTIVE.has(e?.type)) await setTier(e.app_user_id, 'free');
    res.status(200).send('ok');
  });

İptal anında erişim hemen kesilmez — kullanıcı dönem sonuna kadar premium kalır, yalnızca EXPIRATION'da düşürülür. premiumUntil ayrıca saklanır ve bir savunma katmanı olarak kullanılabilir (webhook gecikse bile zaman damgası gelecekteyse premium korunur). Diğer iki fonksiyon: openPlaza (günün kartını döner, plazaStats agregat sayacını artırır) ve reengageLapsed (günlük 17:30 UTC; 3+ gündür açmayan, push token'ı olan kullanıcılara Expo Push ile yeniden-etkileşim bildirimi).

Güvenlik kuralları — neden böyle (firestore.rules)

İstemcinin kendi belgesine yazabileceği alanlar bir whitelist (safeUserKeys) ile sınırlıdır. Kritik: tier ve usage bu listede yoktur — yalnızca kuralları bypass eden Admin SDK (sunucu) onları yazabilir. Kullanıcının kendine premium vermesini ya da kotasını sıfırlamasını engelleyen tek şey budur. diff().affectedKeys().hasOnly(...) kalıbı, update'te yalnızca whitelist alanlarının değiştiğini garanti eder.

firestore.rules
function safeUserKeys() {
  return ['prefs','pushToken','onboardingDone','displayLocale','streak','updatedAt'];
}
match /users/{uid} {
  allow read:   if request.auth != null && request.auth.uid == uid;
  allow create: if request.auth.uid == uid
    && request.resource.data.keys().hasOnly(safeUserKeys());
  allow update: if request.auth.uid == uid
    && request.resource.data.diff(resource.data).affectedKeys().hasOnly(safeUserKeys());
  allow delete: if request.auth.uid == uid;        // KVKK: kullanıcı kendini siler
}
match /dailyPlaza/{day} { allow read: if request.auth != null; allow write: if false; }
match /plazaStats/{day} { allow read: if request.auth != null; allow write: if false; }
match /{document=**} { allow read, write: if false; }   // default deny

dailyPlaza ve plazaStats istemciye salt-okunur, yazımı tamamen sunucuya bırakılmıştır. En sonda bir "default deny" kuralı, tanımlanmamış her yolu kapatır. Bileşik sorgu gerektiren tek erişim reengageLapsed'in lastSeen filtresidir; ilgili indeks firestore.indexes.json'da tanımlıdır.

packages/core/src/plaza.ts — isValidPayload
export function isValidPayload(format: PlazaFormat, p: any): boolean {
  switch (format) {
    case 'trap':      return typeof p.incoming === 'string' && typeof p.reading === 'string'
                          && typeof p.meter === 'number' && p.meter >= 0 && p.meter <= 100;
    case 'bingo':     return Array.isArray(p.cells) && p.cells.length === 9;   // 3×3
    case 'horoscope': return typeof p.sign === 'string' && typeof p.text === 'string';
    case 'riddle':    return typeof p.term === 'string' && typeof p.answer === 'string';
  }
}

admin — Next.js 15 (sunucu-taraflı Admin SDK)

Tüm veri erişimi server component / server action içinde Firebase Admin SDK ile yapılır — anahtarlar tarayıcıya hiç gitmez. Erişim, HMAC imzalı bir cookie ile korunur. verifySession sabit-zamanlı karşılaştırma (timingSafeEqual) kullanır; requireAdmin her korumalı sayfanın başında çağrılır ve geçersizse /login'e yönlendirir.

admin/lib/auth.ts (çekirdek)
export function signSession(payload = 'admin'): string {
  const sig = crypto.createHmac('sha256', SECRET).update(payload).digest('hex');
  return `${payload}.${sig}`;
}
export function verifySession(token?: string): boolean {
  const [p, sig] = (token ?? '').split('.');
  const expected = crypto.createHmac('sha256', SECRET).update(p).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected));
}
export async function requireAdmin() {                 // her korumalı sayfada
  if (!verifySession((await cookies()).get(COOKIE)?.value)) redirect('/login');
}
